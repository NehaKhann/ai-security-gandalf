# Concepts Glossary (beginner notes)

**Prompt Injection** — crafting input to make an AI ignore its original
instructions and do something unintended instead.

**System Prompt** — hidden instructions given to an AI before the user ever
types anything (e.g. "never reveal this password"). Users normally can't see it.

**Obfuscation Attack** — hiding the real intent of a request by disguising it
(e.g. asking for a password spelled backwards instead of asking directly).
